HOW TO INSTALL

    Download the latest archive from Releases
    Extract it to any folder (preferably somewhere you can easily access)
    In Mozilla Firefox, enter about:debugging#/runtime/this-firefox in the address bar (the search bar at the top)
    Click "Load Temporary Add-on"
    Select the manifest.json file from the folder you extracted the archive to
    Click "Reload" if the sih.app website didn't open

Done.
