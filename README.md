**HOW TO INSTALL**

1. Download the latest archive from Releases
2. Extract it to any folder (preferably somewhere with quick access to it)
3. In Mozilla Firefox, enter about:debugging#/runtime/this-firefox in the address bar (the search bar at the top)
4. Click "Load Temporary Add-on"
5. Select the manifest.json file in the folder you extracted the archive to
6. Click "Reload" if the sih.app website didn't open
Done.
